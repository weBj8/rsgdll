On GitHub CI, `cargo xtask test-srcds` timed out because srcds stdout to a pipe is block-buffered; RSGDLL_TEST_DONE lines never flushed (stderr unaffected). Fixed in xtask/src/build.rs run_srcds by launching `stdbuf -oL srcds_run_x64 ... -insecure`. Also CI steamcmd: preseed debconf `steam steam/question select "I AGREE"` and retry app_update ("Missing configuration" on first try). setup-zig `latest` broke; pinned mlugg/setup-zig@v2 version 0.14.1.
